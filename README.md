🛒 ShopEasy – Full Stack E-Commerce Application

ShopEasy is a full-stack E-Commerce web application developed using Java, Spring Boot, React.js, and MySQL. It provides separate User and Admin panels for managing online shopping activities.

🚀 Technologies Used

Backend

- Java
- Spring Boot
- Spring Data JPA
- REST API
- MySQL

Frontend

- React.js
- JavaScript
- HTML5
- CSS3
- Vite

Tools

- IntelliJ IDEA
- VS Code
- MySQL Workbench
- Git & GitHub
- Postman

✨ Features

👤 User Panel

- User Registration and Login
- Browse Products
- View Product Details
- Add Products to Cart
- Manage Shopping Cart
- Place Orders

🔐 Admin Panel

- Admin Login
- Manage Products
- Add New Products
- Update Product Details
- Delete Products
- Manage Orders
- Admin-only Access

⚙️ Installation & Setup

1. Clone Repository

git clone https://github.com/arunkumarrdeveloper/Shopeasy-Ecommerce.git

2. Backend Setup

- Open the backend project in IntelliJ IDEA.
- Configure MySQL database settings.
- Update database credentials in "application.properties".
- Run the Spring Boot application.

3. Frontend Setup

Open the frontend project in VS Code.

Install dependencies:

npm install

Start the development server:

npm run dev

🗄️ Database

- Database: MySQL
- Backend Database Integration: Spring Data JPA

Configure your database connection before running the application.
